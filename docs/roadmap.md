# Roadmap

Open work for OndolSaem, roughly in priority order. Done items move to the release notes in the commit history.

## Planned

1. **More models per category.** Most categories offer one usable model today (`ModelCatalog`: OCR has only ML Kit, speech only SenseVoice, faces only SFace; MobileCLIP2-S0, Moonshine and PP-OCRv5 are listed as *Coming soon*). Add curated alternatives per category, each with a license check (`THIRD_PARTY_NOTICES.md`), a SHA-256, measured size and memory, and a runtime that fits (LiteRT-LM, ML Kit, or ONNX through sherpa-onnx's ONNX Runtime and the JNI bridge, see [architecture.md](architecture.md#faces)). Candidates: MobileCLIP2-S0 (embedding, small, English only), LiquidAI d1-omni 600M / d1-2B for decisions on images and audio (no Korean in d1-omni's languages yet, LFM license, d1-2B about 2 GB; listed as *Coming soon*), Moonshine tiny (speech), PP-OCRv5 mobile (OCR), YuNet as an alternative face detector, smaller or larger chat models (looked at in 0.6.0: Gemma 4 12B, 6.9 GB, for 12 GB phones; a text-only, GPU-only E4B build, 2.97 GB; MiniCPM-V 4.7 1B and Qwen3.5 0.8B VL for describing images, without tool calls).
2. **NPU on real phones.** NPU support (0.6.0, [architecture.md](architecture.md#npu)) is built but only checked on the emulator, which has no NPU (it falls back as it should). Run Settings › NPU › "Check the NPU" (or `scripts/npu-check.sh`) on a Galaxy Z Fold7 (Snapdragon SM8750, Qualcomm QNN runtime downloaded at run time) and, when available, a Pixel 10 and a Dimensity 9400 phone; record load time, speed and the CPU/NPU cosine. If the vectors differ too much (cosine < 0.98), report the NPU build as another model version to clients (re-index) or drop it for embeddings. First Fold7 run (0.6.0 with LiteRT-LM 0.19.0): CPU and GPU fine, NPU failed because the 2.3.2 dispatch library has the older ABI; LiteRT-LM went back to 0.18.1, which matches it. Still open: whether QNN 2.51 runs the context binaries of the published SM8750 files. Upgrade LiteRT-LM again once `litert-npu-runtime` exports `LiteRtDispatchQueryInterface`. NPU builds are found by searching the repositories, so new chips and models need no app update, except a new Snapdragon chip's Hexagon version (`Npu.HEXAGON`). Later: NPU builds of the chat models for Snapdragon (none published yet; Gemma 4 E2B has Tensor builds only).
3. **Real-device numbers.** Run `scripts/bench-device.sh` on real phones (GPU backend, two clients sharing one model) and record the results in [development.md](development.md#measuring-on-a-device). Only emulator CPU numbers exist so far.
4. **Two apps indexing at the same time, end to end.** Per-app turns of background requests (`PriorityGate`) are covered by unit tests only. An end-to-end check needs a second client with its own package name indexing next to Nunsori, and the log showing their requests alternate. Malbotdari (the chat app split out of Nunsori, repository `sonanjip/malbotdari`) is now a second real client, but it only sends interactive chat requests; background turn-taking still needs a second app that indexes (for example a small test client in this repository). Malbotdari can be used to check interactive-before-background ordering: a chat question while Nunsori indexes.

0.9.0 / SDK 0.7.0: request-scoped SenseVoice language hints (API V5), with legacy automatic detection preserved.
